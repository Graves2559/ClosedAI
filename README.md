GitHub Practice Reflection

1. A git commit is used to save changes made in an editor to the clone of the repository on your computer.

2. A git push sends the changes made by the commit to github to be approved. A pull is how a branch or main is added to your local files.

3. A development team uses branches so that they can all work seperately without having to worry about interfering with others work. If a conflict is present, Github clearly shows the conflicting lines so it can be resolved by the team.

4. We had an issue because we all forked off of the same repo, so some of our pushs ended up in each others mains. We had to pay attention to which main we pushed it to.

5. Github will give us a great place to share a codebase that allows us to easily see conflicts and have on-demand access to the code.
